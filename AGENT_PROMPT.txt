Установи мне Yandex Browser MCP из публичного репозитория https://github.com/Dizory/yandex-browser-mcp .
Скачай комплект yandex-browser-mcp-windows.zip и SHA256SUMS.txt из последнего GitHub Release, проверь SHA256 и распакуй в постоянную папку на моём Windows-компьютере. Если папка уже существует, сначала проверь установленную версию и не перезаписывай её вслепую.
Прочитай INSTALL_AGENT.md из комплекта и выполни установку до рабочего соединения: зависимости, локальный MCP-сервер, настройка MCP именно в твоём клиенте и загрузка расширения в мой текущий профиль Яндекс Браузера.
Используй install.ps1 -EnableExtensionUpdates. Учётная запись GitHub не нужна; флаг -RegisterCodex нужен только если настраиваешь Codex. Для другого MCP-клиента добавь отдельную запись, сохранив остальные настройки.
Работай с моими обычными вкладками. Не создавай отдельный профиль браузера. Если доступный тебе инструмент умеет управлять страницей browser://extensions, загрузи расширение сам. Если не умеет, попроси меня только выполнить этот шаг и дай точный полный путь к extension.
Проверь /health (connected=true), доступность 29 инструментов browser_* и 7 sheets_*, затем npm run test:browser. Для личных таблиц отдельно настрой авторизацию Google по README. Не объявляй установку полностью завершённой без подключения расширения и успешного теста. Сообщи, как запускать сервер после перезагрузки компьютера.
